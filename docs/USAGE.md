# CANログ取得治具 操作手順書

現場でCANログを取得し、解析側へ送るまでの手順。

---

## 1. 治具の構成

```
┌─────────────────────────────────┐
│  [LED]        [開始]  [停止]     │
│                                 │
│  [CH1]  [CH2]        [USB-C]    │
│  500k   250k          [SD]      │
└─────────────────────────────────┘
```

| 部位 | 用途 |
|---|---|
| CH1コネクタ | 測定対象の**500kbps**バスへ接続 |
| CH2コネクタ | 測定対象の**250kbps**バスへ接続 |
| 開始ボタン | 記録開始 |
| 停止ボタン | 記録停止 |
| LED | 状態表示（§3） |
| USB-C | 電源。**モバイルバッテリー**から給電 |
| microSD | ログの保存先 |

> **CH1とCH2のコネクタは同じ形状です。** ケーブルのタグと基板の刻印を必ず確認してください。
> 挿し間違えてもエラーは出ず、**そのチャネルだけ0件で終わります**（§6で確認できます）。

---

## 2. 準備

### 事前に用意するもの

- microSDカード（FAT32でフォーマット済み、8GB程度で十分）
- USBモバイルバッテリー
- CAN接続ケーブル（CH1用・CH2用）

### 接続

1. microSDカードを挿す
2. USBモバイルバッテリーを繋ぐ
3. LEDが**消灯**していることを確認する（＝準備完了）

> **LEDが高速点滅する場合**は異常です。§5を確認してください。

---

## 3. LEDの見方

| LED | 状態 | 意味 |
|---|---|---|
| **消灯** | 待機 | 準備完了。開始ボタンを押せる |
| **ゆっくり点滅**（1秒に2〜3回） | 記録中 | **SDカードを抜かないこと** |
| **点灯したまま** | 停止完了 | **SDカードを抜いてよい** |
| **高速点滅**（1秒に6回） | 異常 | §5を参照 |

**覚えることは1つだけです。**

> **点滅している間はSDカードを抜かない。点灯に変わってから抜く。**

---

## 4. 記録の手順

### 手順

| # | 操作 | 確認すること |
|---|---|---|
| 1 | 電源を入れる | LEDが**消灯** |
| 2 | CH1・CH2のケーブルを接続する | タグと刻印が合っているか |
| 3 | **開始ボタン**を押す | LEDが**点滅を始める** |
| 4 | 事象を再現させる | — |
| 5 | **停止ボタン**を押す | LEDが**点灯に変わるまで待つ** |
| 6 | SDカードを抜く | LEDが点灯していること |

### 注意

- **停止ボタンを押してから、LEDが点灯に変わるまで数秒かかります。** 焦らず待ってください
- 点滅中にSDカードを抜くと**ファイルが壊れます**
- 記録中に電源が切れた場合も、そこまでのデータは残っていることが多いです。SDカードを抜いて解析側へ送ってください
- 記録は自動では止まりません。**必ず停止ボタンを押してください**

### 記録時間の目安

| 記録時間 | ファイルサイズの目安 |
|---|---|
| 1分 | 約2 MB |
| 10分 | 約20 MB |
| 1時間 | 約120 MB |

8GBのSDカードなら数十時間分記録できます。**長めに録っても問題ありません。**

---

## 5. 異常時の対応

LEDが**高速点滅**したときの対処です。

| 状況 | 確認すること |
|---|---|
| 電源投入直後から高速点滅 | SDカードが挿さっているか。別のカードで試す |
| 開始ボタンを押したら高速点滅 | SDカードの空き容量。書き込み禁止になっていないか |
| 記録中に高速点滅に変わった | SDカードの接触不良か容量不足。**そこまでのログは保存されています** |

### 復帰のしかた

1. **開始ボタンを押す**と再試行します
2. 直らない場合は電源を入れ直す
3. それでも直らない場合は、SDカードを抜いて管理者へ連絡してください

**高速点滅になっても、それまでに記録したログとエラー内容はSDカードに残っています。**
カードを抜いて解析側へ送れば、原因が分かります。

---

## 6. 記録後の確認（重要）

SDカードには2つのファイルができます。

| ファイル | 内容 |
|---|---|
| `LOG0001.BIN` | CANログ本体 |
| `LOG0001.TXT` | **記録結果のレポート** |

**`LOG0001.TXT` をメモ帳で開いて、以下を確認してください。**

```
exit            : normal (stop button)      ← ここが normal であること

-- CH1 (internal TWAI) --
frames logged   : 2747                      ← 0 でないこと
ring dropped    : 0   (frames)              ← 0 であること
ctrl missed     : 0   (frames)              ← 0 であること

-- CH2 (MCP2515) --
frames logged   : 54263                     ← 0 でないこと
ring dropped    : 0   (frames)              ← 0 であること
ctrl ovf events : 0   (events, not frames)  ← 0 であること

result          : OK                        ← これが出れば全部問題なし
```

### 判定

| 表示 | 意味 | 対応 |
|---|---|---|
| `result : OK` | **問題なし** | そのまま送付 |
| `CH1 received nothing` | CH1が0件 | **ケーブルの挿し間違い**の可能性。接続を確認して録り直す |
| `CH2 received nothing` | CH2が0件 | 同上 |
| `frame loss detected` | 取りこぼしあり | 送付してよいが、解析側へ一報 |
| `exit : ABNORMAL` | 異常終了 | `fault` 行の内容とあわせて管理者へ連絡 |

> **片方だけ0件の場合は、ほぼ挿し間違いです。** CH1とCH2のケーブルを入れ替えて録り直してください。

---

## 7. 解析側への送付

以下をセットで送ってください。

- `LOG0001.BIN`（ログ本体）
- `LOG0001.TXT`（レポート）
- **記録した日時**（治具のRTCが未設定の場合に必要）
- 現地の状況（何をしたときに、どんな事象が起きたか）

ファイルは記録するたびに `LOG0002`, `LOG0003`... と番号が増えます。
**複数回記録した場合は、どれがどの事象か分かるようにメモを添えてください。**

---

## 8. やってはいけないこと

| 禁止事項 | 理由 |
|---|---|
| **点滅中にSDカードを抜く** | ファイルが壊れる |
| **測定中にPCを接続する** | グランドループができて治具や測定対象を壊す恐れがある |
| **高電圧のバスに接続する** | この治具は**制御系CAN専用**です |
| コネクタを無理に挿す | CH1とCH2は形状が同じです。タグを確認してください |

---

## 9. 困ったときは

| 症状 | 対応 |
|---|---|
| LEDが全く点かない | モバイルバッテリーの残量。USBケーブルを替えてみる |
| 開始ボタンを押しても点滅しない | LEDが高速点滅していないか確認（§5） |
| SDカードが認識されない | FAT32でフォーマットし直す |
| ファイルが作られない | SDカードの空き容量と書き込み禁止スイッチ |

上記で解決しない場合は、**SDカードを抜いて管理者へ連絡**してください。
